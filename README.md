## ZAYAN

ZAYAN is an independent web design and front-end development project inspired by Moroccan jewelry, cultural heritage, and contemporary digital design.

The project explores how traditional Moroccan visual identity can be translated into a modern and immersive web experience while preserving a strong connection to its cultural inspiration.

## My Role

I independently worked on the concept, visual direction, interface design, and front-end development of the project.

## What I Worked On

- Brand and visual direction
- Web and interface design
- Front-end development
- Responsive web experience
- Integration of Moroccan-inspired visual elements and storytelling
